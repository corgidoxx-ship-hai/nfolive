# แผน: เว็บแอปโหวตเกม + โดเนท (GameVote)

## ภาพรวม

เว็บแอป responsive สำหรับ FC โหวตเกมที่อยากให้เจ้าของช่องเล่น พร้อมเลือกช่องทางนำเสนอ (Live / อัดคลิป / ทั้งสอง) และปุ่มโดเนทผ่าน QR PromptPay + เลขบัญชี รันได้ทั้ง PC และสมาร์ตโฟน

## สิ่งที่ต้องตั้งค่าก่อนสร้าง

- **Lovable Cloud** — ฐานข้อมูล + ระบบล็อกอิน (จำเป็นเพราะต้องเก็บโหวต/เกม/ผู้ใช้)
- **ระบบล็อกอิน**: Google (gmail + YouTube) + Microsoft (Hotmail) + Email/password
  - TikTok ไม่รองรับในตัว — เก็บไว้ทำเพิ่มภายหลังได้ถ้าต้องการ
  - จุดประสงค์หลัก: กันโหวตซ้ำ (1 โหวต/เกม/วัน ต่อคน)

## โครงสร้างฐานข้อมูล

- `games` — id, title, description, cover_image_url, status (approved/pending), created_by, deadline (nullable), created_at
- `votes` — id, game_id, user_id, channel (live/clip/both), vote_date (date), created_at
  - unique constraint (game_id, user_id, vote_date) บังคับ 1 โหวต/เกม/วัน
- `user_roles` — admin role สำหรับเจ้าของช่อง (ตารางแยก ไม่ใช่ field ใน profile)
- `donation_settings` — QR PromptPay image URL, เลขบัญชี, ชื่อบัญชี, is_live (สถานะกำลังไลฟ์), overlay_token (คีย์ลับสำหรับลิงก์ overlay), alert_sound_url, alert_volume, tts_enabled, tts_voice, tts_speed, tts_template
- `donations` — id, donor_name, amount, message, slip_image_url, status (pending/approved/rejected), tts_audio_url, shown_at, created_at
- ทุกตารางมี RLS policies + GRANT ตามมาตรฐาน
- Storage buckets: สลิปโอนเงิน, QR code, ไฟล์เสียงที่อัปโหลด, ไฟล์เสียง TTS ที่สร้าง

## ฟีเจอร์สำหรับ FC (คนดู)

1. **หน้าแรก** — รายการเกมที่เปิดโหวตเป็นการ์ด แสดงจำนวนโหวตรวม + breakdown ตามช่องทาง (Live/คลิป/ทั้งสอง)
2. **ขั้นตอนโหวต** — เลือกเกม → เลือกช่องทาง → ยืนยัน (ต้องล็อกอินก่อน)
3. **เสนอเกมใหม่** — FC กรอกชื่อเกม + คำอธิบาย → เข้าคิวรอ admin อนุมัติ
4. **ปุ่มโดเนท** — popup/modal แสดง QR PromptPay ใหญ่ๆ + เลขบัญชี + ชื่อบัญชี ให้สแกน/โอนเอง
   - ถ้ากำลังไลฟ์อยู่: มีฟอร์มให้กรอกชื่อ + ข้อความ + จำนวนเงิน + แนบสลิป เพื่อส่งขึ้นหน้าจอไลฟ์
   - แสดงป้าย "กำลังไลฟ์อยู่ตอนนี้" เมื่อ admin เปิดสถานะไลฟ์
5. **ล็อกอิน** — หน้า auth ให้เลือก Google / Microsoft / Email-password

## ฟีเจอร์สำหรับ Admin (เจ้าของช่อง)

1. เพิ่ม/แก้ไข/ลบเกม (พร้อมรูปปก)
2. อนุมัติ/ปฏิเสธเกมที่ FC เสนอ
3. ตั้ง deadline โหวต (optional, ทำได้ทีหลัง เกมละตัว)
4. แก้ไขข้อมูลโดเนท (อัปโหลด QR + แก้เลขบัญชี/ชื่อบัญชี)
5. ดูสรุปผลโหวตแบบ real-time
6. **ปุ่มเปิด/ปิดสถานะไลฟ์** — กดเปิดตอนเริ่มไลฟ์ ปิดตอนจบ
7. **คิวโดเนทรออนุมัติ** — เห็นชื่อ/ข้อความ/สลิปที่ FC ส่งมา กดอนุมัติแล้วข้อความเด้งขึ้นหน้าไลฟ์ทันที (กันข้อความไม่เหมาะสม/โดเนทปลอม)

## ระบบแจ้งเตือนโดเนทขึ้นหน้าไลฟ์ (Donation Alert Overlay)

หน้าเว็บพิเศษ `/overlay/<token>` — พื้นหลังโปร่งใส ออกแบบมาให้เอาไป
ใส่เป็น Browser Source ใน OBS / Streamlabs โดยเฉพาะ

การทำงาน:

```text
FC โอนเงินผ่าน QR  →  กรอกชื่อ+ข้อความ+แนบสลิป
                            ↓
              เข้าคิวรออนุมัติในหน้า Admin
                            ↓
                  พี่ปี๊กดอนุมัติ
                            ↓
      ข้อความเด้งขึ้นหน้าจอไลฟ์ทันที (realtime) พร้อมอนิเมชัน
```

- ใช้ realtime ของ Lovable Cloud ทำให้ข้อความขึ้นทันทีโดยไม่ต้องรีเฟรช
- ลิงก์ overlay มีโทเคนลับ ใครไม่มีลิงก์เข้าไม่ได้
- คิวจัดการทีละข้อความ แสดงประมาณ 8 วินาทีแล้วเลื่อนไปข้อความถัดไป
- ปุ่ม "ทดสอบ" ในหน้า admin สำหรับเช็คว่า overlay ทำงานก่อนไลฟ์จริง
- **ใช้ได้กับทุกแพลตฟอร์มไลฟ์** — OBS, YouTube (ผ่าน OBS), และ TikTok Live Studio ล้วนรองรับ Browser Source เหมือนกัน เอาลิงก์ overlay ไปแปะได้เลย
  - หมายเหตุ: ดึงข้อมูลของขวัญ (gifts) จาก TikTok Live โดยตรงไม่ได้ — TikTok ไม่เปิด API ส่วนนี้ให้ทั่วไป แต่โฟลว์ของเราไม่จำเป็นต้องใช้
  - ล็อกอินด้วย TikTok ไม่รองรับในตัวของ Lovable Cloud — ทำเพิ่มภายหลังได้ถ้าต้องการ

**ข้อจำกัดที่ต้องรู้:** เพราะเราใช้ QR PromptPay (โอนตรงเข้าบัญชี ไม่ผ่านระบบจ่ายเงิน)
ระบบจะไม่รู้เองว่าเงินเข้าจริงหรือยัง จึงต้องให้พี่ปี๊กดอนุมัติเองก่อนข้อความขึ้นจอ
ซึ่งจริงๆ ดีกว่าด้วยเพราะกันข้อความกวนได้ไปในตัว
_ถ้าอยากให้ขึ้นอัตโนมัติไม่ต้องกดอนุมัติ ต้องเปลี่ยนไปใช้ระบบจ่ายเงินจริง (Stripe) แทน — บอกผมได้ครับ_

## เสียงแจ้งเตือน + เสียงอ่านข้อความ (Sound & Voice)

เมื่อข้อความโดเนทเด้งขึ้นจอ จะเล่นเสียง 2 จังหวะต่อกัน:

```text
อนุมัติโดเนท → [1] เสียงแจ้งเตือน "ติ๊ง!" → [2] เสียงคนอ่านข้อความ
                   (0.5-1 วิ)              "คุณสมชาย โดเนท 100 บาท
                                            บอกว่า สู้ๆนะครับ"
```

**เสียงแจ้งเตือน (ตอนข้อความเด้ง)**

- มีเสียงสำเร็จรูปให้เลือก 5-6 แบบ (ระฆัง, coin, เกมเรโทร, ฯลฯ) พร้อมปุ่มกดฟังตัวอย่าง
- **อัปโหลดไฟล์เสียงเองได้** — mp3/wav ผ่านหน้า admin
- ปรับระดับเสียงได้

**เสียงคนอ่านข้อความ (Text-to-Speech)**

- ใช้ AI แปลงข้อความเป็นเสียงพูด **อ่านภาษาไทยได้**
- เลือกเสียงได้: **ชาย / หญิง** และหลายบุคลิก (สดใส, นุ่มลึก, สนุกสนาน ฯลฯ) — มีปุ่มฟังตัวอย่างก่อนเลือก
- ปรับความเร็วในการอ่านได้
- แก้ไขรูปแบบประโยคที่จะอ่านได้ เช่น `"{ชื่อ} โดเนท {จำนวน} บาท บอกว่า {ข้อความ}"`
- เปิด/ปิดได้ ถ้าวันไหนไม่อยากให้มีเสียงอ่าน
- เสียงจะถูกสร้างตอน admin กดอนุมัติ แล้วเก็บไว้ ไม่สร้างซ้ำ

**ตั้งค่าทั้งหมดอยู่ในหน้า admin แท็บ "เสียง"** พร้อมปุ่มทดสอบยิงโดเนทปลอมขึ้น overlay เพื่อเช็คเสียงก่อนไลฟ์จริง

## กฎการโหวต (ตั้งข้อสังเกตให้พี่ปี๊ยืนยัน)

- **1 โหวต/เกม/วัน ต่อคน** — สามารถกลับมาโหวตซ้ำวันถัดไปเพื่อสะสมคะแนน (เพราะเปิดโหวตตลอดเวลา)
- ถ้าเกมนั้นมี deadline: ปิดโหวตอัตโนมัติวันที่กำหนด แล้วแสดงผลลัพธ์
- _หากต้องการ "1 โหวตต่อคนตลอดกาล" แทน บอกผมปรับได้เลย_

## ขั้นตอนการสร้าง

1. เปิดใช้งาน Lovable Cloud (ฐานข้อมูล + auth)
2. นำเสนอ **3 ทิศทางดีไซน์** → พี่ปี๊เลือก 1 แบบ → สร้างตามสไตล์ที่เลือก
3. สร้าง migration ฐานข้อมูล (schema + RLS + GRANT + seed ตัวอย่างเกม)
4. ตั้งค่าล็อกอิน (Google + Microsoft + Email/password)
5. สร้างหน้า public (โหวต + เสนอเกม + โดเนท) — responsive จอใหญ่/มือถือ
6. สร้างหน้า admin (จัดการเกม + อนุมัติ + โดเนท settings + ผลโหวต + คิวโดเนท + สวิตช์ไลฟ์)
7. สร้างหน้า overlay สำหรับ OBS + ระบบ realtime แจ้งเตือนโดเนท
8. ทำระบบเสียง — เสียงแจ้งเตือน (เลือก/อัปโหลด) + เสียงอ่าน AI ภาษาไทย ชาย/หญิง + แท็บตั้งค่าเสียง
9. ตรวจสอบ build + ทดสอบการโหวต overlay และเสียงจริง
